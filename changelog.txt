# Changelog

- Rebranded public plugin surfaces from Coppelia to HealBot while retaining the Coppelia assembly, namespace, configuration/InternalName, repository, URLs, version, release workflow, and existing `Coppelia.QST` IPC identities for compatibility. Added `/hb` while keeping `/healbot` and `/copellia`.
- Added Newb as the fourth mutually exclusive mode. Newb performs no local healing or attacking and directly pairs one exact name/home-world client to one active HealBot for healing and chase.
- Added opt-in one-to-one IPv4 pairing with default TCP port 47790, reserved-port validation, a minimum 16-character pair secret, HMAC-SHA256 authenticated envelopes, two-minute freshness, five-minute replay rejection, 64-KiB newline frames, correlated acknowledgements, five-second status, and 1/2/5/10-second reconnect delays without a new package or UDP discovery.
- Unified QST and direct Newb assignments under the existing exact ephemeral-target owner so they cannot overlap. Disconnect, stop, mode change, pairing restart, and unload release the paired target and owned navigation; stale direct sessions are released before a fresh assignment.
- Reused the existing travel engine for an immediate post-assignment snapshot and updates no faster than 750 ms after three yalms of movement or mount, flight, world, territory, or accepted-teleport changes.
- Added `/healbot mini` (also `/hb mini` and `/copellia mini`) with four-mode selection, Start/Stop, role-aware address/port/secret controls, secret generation/copy, pairing save/restart, and live connection, identity, blocker, runtime, healing, and chase status.
- Added Newb selection and pairing status to Main, Settings, Quick Setup, Watch, DTR, command help, requirements, manifests, and README. The UI and README explicitly warn that pairing traffic is authenticated but not encrypted, so names and coordinates remain visible on the network.
- Prevented stale watched targets from reaching native targeting or heal action calls by resolving exact live battle characters at each boundary.
- Prevented HealBot status-list crashes by re-resolving live targets and skipping actions when tracked status cannot be read safely.
- Replaced Coppelia's QST aetheryte discovery with LootGoblin parity: every exact and fallback decision now uses one refreshed helper teleport-list snapshot with ID/sub-index/cost, territory and optional Tamamizu filtering, stored/default positions (including Hawthorne Hut ID 4), complete Level and MapMarker fallbacks, community map overrides/RealXYZ, XYZ-or-XZ distance selection, and cheapest-cost fallback; successful teleports also passively validate and record arrival positions.
- Added deterministic QST territory handoff: an observed physical crossing gets one non-resetting five-second forward move before nearest-aetheryte fallback from the helper's refreshed teleport list in the latest destination territory, while initial/reload mismatches and explicit world or teleport travel bypass the blind probe; newer snapshots re-arm blocked destinations and stale exact intent cannot override a newer different destination.
- Moved QST travel holds behind successful heal, JOAT, powerlevel, mount, and companion actions, prioritized active casts and travel handoffs ahead of ordinary holds, and added transition-only destination, handoff, Lifestream, fallback, blocker, and accepted-action diagnostics.
- Advanced `Coppelia.QST.Status` and `Coppelia.QST.Command` to version 3 with mounted/flying travel state, explicit older-peer blockers, idempotent activation, exact assignment, monotonic travel, DAD-owned duty, inside-duty, release, and deactivation commands plus separate JOAT, travel, and DAF readiness/state.
- Added QST-owned JOAT activation that survives connection churn, an exclusive in-memory exact Quester target that appears immediately while remote, Lifestream world/territory synchronization, exact or nearest-unlocked aetheryte travel, and party-independent latched follow: mounted follow resumes beyond 30 yalms and stops at 5, while on-foot follow resumes beyond 20 and stops at 10.
- Added native Mount Roulette mirroring, catch-up mounting beyond 50 yalms, flight-first mounted chases, 20-yalm on-foot landing/dismount handoff, grounded-Quester landing at 5 yalms while remaining mounted, safe ground fallback blockers, and single-route ownership that pauses active movement without routine navmesh reloads.
- Stabilized route ownership so moving 750-ms snapshots never replace active/pending work, accepted-but-never-active startups reject once, completed routes advance only to newer coordinates, action holds use Path.Stop, and only terminal release can cancel one owned pending pathfind.
- Added explicit Locked, Unlocked, and UnknownButMountable flight policy. Mountable ARR territories such as Central Thanalan probe one fly-to startup, retain proven flight for the territory, and visibly fall back to ground after a rejected/non-starting probe until territory or session reset.
- Repaired world/territory handoff with travel-sequence-owned Lifestream requests, exact unlocked teleport preservation, newest-coordinate nearest-aetheryte fallback, visible no-unlocked-aetheryte blockers, and terminal failure when a request never becomes busy or finishes at the wrong target.
- Added local-only `Coppelia.QST.SetCompanionSummoning` ownership and a 15-second companion service that safely uses Gysahl Greens below 900 seconds only while on foot and otherwise eligible. QST deactivation, role/provider loss, plugin disable, and unload clear ownership; companion stance remains untouched.
- Paired HealBot now retains full prebuff/heal/raise ownership and JOAT uses the exact visible assigned Quester as its protected combat leader only after healing yields.
- Added idempotent multi-duty DAF ownership: Quester-owned entry waits for stable FrenRider/ADS handoff, while Coppelia-owned entry keeps the helper as leader and configures DAD for Regular + Unsynced. Missing assignment, metadata, dependency, or IPC readiness fails closed.
- Renamed displayed Jacqueline of All Trades shorthand to JOAT. `/healbot joat` is now primary while `/healbot jot` remains a compatibility alias; internal `Jot` configuration and symbols are unchanged.
- Added Jacqueline of All Trades (JOAT) as a serialized third mode with `/healbot joat`, DTR/UI selection and separate healing/attacking status. JOAT reuses the HealBot watch list and action matrix, gives every 900-ms healing decision absolute priority, and only then directly casts the equipped healer's highest available single-target filler spell on an eligible damaged enemy already targeting the configured visible Fren or local healer; DoTs, AoE, oGCD attacks, untouched enemies, and the Powerlevel job selector are excluded.
- Added a permanent Quick Setup tab with draft-only HealBot, JOAT, and PowerlevelBot paths, explicit enable-now or leave-off completion, first-install onboarding, migration suppression for existing users, and visible activation blockers.
- Reorganized Main into a status dashboard and Settings into Quick Setup, General, HealBot Actions, and Requirements / Help tabs.
- Restyled Watch status, target controls, filters, and retained/live target tables while preserving selection, Ctrl-clear, persistence, filtering, and window placement behavior.
- Added shared UI helpers for section headings, readiness colors, wrapped help, tooltips, and primary actions.
- Updated the public plugin description for all three automation modes and synchronized the repository manifests and README.
- Added schema-v6 migration coverage for new-install onboarding, existing-configuration suppression and preservation, and completed-setup persistence.
